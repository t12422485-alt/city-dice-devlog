# 03 本機安裝教學

以「骰子電玩城」為例：Node.js 伺服器＋瀏覽器前端。
遊戲原始碼目前是**私人儲存庫**，以下步驟同樣適用於一般的 Node.js（Socket.IO）專案，把專案網址與資料夾換成自己的即可。

---

## 需要的軟體

| 軟體 | 版本 | 取得 |
|---|---|---|
| Node.js | 22 或 24 LTS（本專案在 22、24 測試過；最低 20） | <https://nodejs.org>（npm 會一起安裝） |
| Git | 新版即可 | <https://git-scm.com> |
| 瀏覽器 | 新版 Chrome、Edge、Firefox 或 Safari（需要 WebGL） | — |

安裝完成後，**重新打開**終端機再繼續，新安裝的指令才會生效。

---

## Windows：先分清楚 PowerShell 和 CMD

Windows 有兩種常見的命令列，指令寫法不一樣：

| | PowerShell | 命令提示字元（CMD） |
|---|---|---|
| 怎麼打開 | 開始選單搜尋「PowerShell」，或 Windows 終端機的預設分頁 | 開始選單搜尋「cmd」 |
| 提示字元長相 | `PS D:\Projects>` | `D:\Projects>` |
| 設定環境變數 | `$env:PORT=4000` | `set PORT=4000` |
| 串接兩個指令 | `指令1; 指令2` | `指令1 && 指令2` |

### 為什麼 PowerShell 要用 `npm.cmd`

在 PowerShell 輸入 `npm`，實際執行的是 `npm.ps1` 腳本。如果系統不允許執行腳本，會看到類似這樣的錯誤：

```text
npm : 因為這個系統上已停用指令碼執行，所以無法載入檔案 ...\npm.ps1
```

最簡單的做法是**改打 `npm.cmd`**：它是同一個 npm，只是不經過 PowerShell 腳本，不需要改任何系統設定。
（`npx` 同理，改用 `npx.cmd`。）

> 也可以調整 PowerShell 的執行原則，但這是系統安全設定，請自行評估；本教學一律用 `npm.cmd`，不需要修改。

## Windows 步驟

### PowerShell 版

```powershell
# 1. 確認版本
node --version
npm.cmd --version

# 2. 取得專案（換成你的儲存庫網址與資料夾）
git clone https://github.com/<你的帳號>/<專案>.git D:\Projects\city-dice
cd D:\Projects\city-dice

# 3. 依 package-lock.json 安裝相同版本的套件
npm.cmd ci

# 4.（選擇性）跑測試
npm.cmd test

# 5. 啟動
npm.cmd start
```

換連接埠或設定存檔資料夾（**同一個視窗**內設定後再啟動）：

```powershell
$env:PORT=4000
$env:DATA_DIR="D:\city-dice-data"
npm.cmd start
```

### CMD 版

```bat
node --version
npm --version

git clone https://github.com/<你的帳號>/<專案>.git D:\Projects\city-dice
cd /d D:\Projects\city-dice

npm ci
npm test
npm start
```

CMD 裡可以直接打 `npm`（它本來就會執行 `npm.cmd`）。換資料夾到其他磁碟要加 `/d`。設定環境變數：

```bat
set PORT=4000
set DATA_DIR=D:\city-dice-data
npm start
```

### 用 `.env` 檔設定（PowerShell 和 CMD 都一樣）

專案附有不含機密的範本 `.env.example`：

```powershell
Copy-Item .env.example .env      # CMD：copy .env.example .env
npm.cmd run start:env            # CMD：npm run start:env（需要 Node.js 20.6 以上）
```

`.env` 已被 `.gitignore` 排除，不會上傳到 GitHub。

### 啟動之後

- 打開 `http://localhost:3000`（或你設定的連接埠）。
- 同一個 Wi-Fi 的手機：用伺服器啟動時顯示的 `http://192.168.x.x:3000`。第一次啟動時 Windows 可能跳出防火牆詢問，允許「私人網路」即可。
- 停止伺服器：在該視窗按 **Ctrl + C**。
- 「連接埠已被使用」：代表有其他程式在用那個連接埠，換一個（例如 `$env:PORT=3005`），不要隨便結束不知道是什麼的程式。

## Linux（Debian／Ubuntu）

```bash
node --version     # 建議用 nodejs.org 官方版本；部分發行版內建的版本已停止支援
git clone https://github.com/<你的帳號>/<專案>.git
cd <專案>
npm ci
npm test           # 選擇性
PORT=3000 DATA_DIR=./data npm start
```

---

## 環境變數

| 變數 | 說明 | 預設 |
|---|---|---|
| `PORT` | 監聽的連接埠 | `3000` |
| `HOST` | 監聽位址；放在反向代理後面時用 `127.0.0.1` | `0.0.0.0` |
| `DATA_DIR` | 房間存檔資料夾；設定後重啟會恢復房間 | 不設定＝只存在記憶體 |
| `MAX_ROOMS` | 同時最多幾間房 | `500` |

這個遊戲本身**不需要任何密碼、API 金鑰或 Token**。

## 存檔備份與還原（本機）

```powershell
# 備份（DATA_DIR=.\data 時）
Compress-Archive -Path .\data -DestinationPath D:\backup\city-dice-data.zip
# 還原：先關伺服器，再解壓回專案資料夾
Expand-Archive D:\backup\city-dice-data.zip -DestinationPath . -Force
```

存檔裡有玩家的重連憑證，不要公開分享或提交到 Git。
