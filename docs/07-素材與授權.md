# 07 素材與授權

公開前逐項確認來源。**來源或授權還沒確認的素材，一律不放進這個儲存庫。**

## 遊戲內容

| 素材 | 來源 | 公開展示 |
|---|---|---|
| 六位原創角色（皮可、喵財、阿磚、浣浣、龜龜、小焰）的 3D 模型 | 本專案原創，用 Three.js 程式組成（沒有外部模型檔） | ✅ 放在截圖中 |
| 城市、道路、建築、樹木等 3D 場景 | 本專案原創，程式產生 | ✅ |
| 背景音樂與音效 | 本專案原創，用 Web Audio API 即時合成（沒有音訊檔、沒有使用其他遊戲的原聲帶或付費素材） | ✅（截圖沒有聲音） |
| 介面、圖示 | 本專案的 CSS 與系統 Emoji | ✅ |
| 一位以既有動畫作品角色為造型依據的同人角色 | **不是原創**，著作權屬原權利人 | ❌ 不放截圖、不放模型 |
| 三位依作者提供的參考圖製作的角色 | 參考圖的來源與授權**尚未確認** | ❌ 確認前不放 |
| 一位依文字描述製作的角色 | 依作者決定不公開 | ❌ 不放 |
| 大廳與對局的參考截圖、角色參考圖 | 作者蒐集的參考資料，不是本專案的作品 | ❌ 不放 |

> 遊戲的整體視角參考了經典斜角俯視大富翁遊戲的呈現方式；角色、建築與美術都是本專案自行製作，沒有使用該遊戲的素材。
