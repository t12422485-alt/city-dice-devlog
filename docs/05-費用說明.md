# 05 費用說明

本文**不寫沒有確認過的價格**。要付費的項目，請以各服務官方頁面當下的價格為準。

## 免費

| 項目 | 用途 | 說明 |
|---|---|---|
| Node.js、npm | 執行遊戲伺服器 | 開源軟體 |
| Three.js、Socket.IO | 3D 畫面、即時連線 | 開源套件（MIT 授權） |
| Git | 版本管理 | 開源軟體 |
| Caddy | HTTPS 與反向代理 | 開源軟體；用 Debian 官方套件安裝 |
| Let's Encrypt | HTTPS 憑證 | 免費，Caddy 自動申請與更新 |
| DuckDNS | 固定網址（`xxx.duckdns.org`） | 免費子網域，用 GitHub 或 Google 帳號登入 |
| Cloudflare 臨時通道 | 從自己的電腦臨時分享（開發初期用過） | 不需要帳號；網址每次重開都會換，電腦要開著 |
| GitHub | 存放原始碼與教學 | 本專案使用的私人與公開儲存庫功能不需要付費 |
| 遊戲內的音樂、音效、3D 模型 | — | 全部由程式產生，沒有購買素材 |
| 電腦玩家（AI 對手） | — | 伺服器上的規則程式，**不呼叫任何付費 API** |

## 可能產生費用

| 項目 | 本專案的狀況 | 怎麼確認價格 |
|---|---|---|
| **VPS 主機** | 使用作者**原本就有**的一台 VPS（1 vCPU、512 MB），這次部署**沒有**新增主機或付費項目 | 依主機商官方方案頁與自己的帳單 |
| **AI 服務**（ChatGPT、Claude Code） | 開發全程使用；依作者自己的訂閱方案或用量計費 | 依 OpenAI、Anthropic 官方方案頁 |
| 自己的網域（選配） | 沒有使用，改用免費的 DuckDNS | 依網域註冊商 |
| 雲端平台（例如 Fly.io、Railway、Render） | 只做了比較和 Fly.io 帳號登入，**沒有建立任何收費資源** | 依各平台官方價格頁 |
| 主機流量 | 依 VPS 方案內含的流量；第一次載入要下載約 2.5 MB 的程式檔（傳輸時有壓縮，實際流量更少），之後對局只有很小的連線資料 | 依主機商方案 |

## 注意事項

- 部分雲端平台**部署前要綁信用卡**，而且**沒有花費上限**。開始前先確認：是否有花費通知、通知能不能自動停止扣款（通常不能）。
- 雲端平台的「免費方案」常常**沒有持久磁碟**（重啟後房間會消失），或閒置時會休眠，不適合需要存檔的連線遊戲。
- AI 協作時，要求 AI「**先不要建立收費資源，等我確認方案和費用**」，並在每個會產生費用的步驟停下來確認（範本見 [02 AI 協作與提示詞](02-AI協作與提示詞.md)）。
